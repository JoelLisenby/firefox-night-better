Proxy

Off

Proxy is turned off until you allow Night Better in Private Windows. Firefox uses one proxy setting for normal and private windows, so the add-on is not allowed to change it without that permission.

Type about:addons in the address bar. Next to Night Better, open ... → Manage. Set Run in Private Windows to Allow. Firefox blocks add-ons from opening that page. Temporary add-ons need this granted again after each load.

Turns your current Firefox proxy on and off. Host, port, PAC, and type load from the settings you already had. Edit them on the options page; Firefox Connection Settings stays locked while Night Better owns the proxy.

Opens the options page. You paste userChrome.css into your profile; the add-on cannot apply it by itself.
