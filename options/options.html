Night Better

Night Neutral is a separate theme add-on. This page edits the Firefox proxy (loaded from your current settings) and ships the chrome CSS the extension cannot apply by itself.

Connection Settings

Off

These fields load from your current Firefox proxy. Night Better does not write them until you change a control. Firefox Connection Settings stays locked while this add-on owns the proxy, so this form is the editor.

Proxy controls are disabled until you allow Night Better in Private Windows. Firefox uses one proxy setting for normal and private windows, so the add-on cannot change it without that permission. Type about:addons in the address bar. Next to Night Better, open ... → Manage. Set Run in Private Windows to Allow. Firefox blocks add-ons from opening that page. Temporary add-ons need this granted again after each load. Your current values still show below.

On/Off is the same as the toolbar switch. It keeps host, port, PAC, and bypass, and only changes the type between No proxy and your last type.

Configure Proxy Access to the Internet

Example: .mozilla.org, .net.nz, 192.168.1.0/24

Connections to localhost, 127.0.0.1/8, and ::1 are never proxied.

Firefox Connection Settings has separate SOCKS v4 and v5 DNS boxes. The add-on API has one Proxy DNS flag, so this checkbox is that flag.

Chrome CSS

Night Neutral follows the official theme keys. Those keys do not include border radius or toolbox layout, so Nova’s rounding, tab padding, and purple top-bar gradient stay unless you install userChrome.css. Leave browser.nova.enabled on. The CSS also tightens tab spacing, paints the top bar solid #000000, and lifts the current tab and hover/active chrome just off black.

0 Nova

0 is square. 100 is Nova’s default rounding. Copy userChrome.css after you change this, then restart Firefox.

  1. Open about:config, set toolkit.legacyUserProfileCustomizations.stylesheets to true.
  2. Open about:support → Profile Folder → Open Folder.
  3. Create a folder named chrome if it is missing.
  4. Paste the CSS below into userChrome.css. For Settings and other about: pages, also paste the userContent.css block into userContent.css.
  5. Restart Firefox.

Share Firefox

Share Firefox sits in the app menu next to About Firefox. The userChrome.css above hides those Share items. You can also set browser.referrals.enabled to false in about:config.
